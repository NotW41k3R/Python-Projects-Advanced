Cafe API

REST API for cafes

GET

/random

Returns a random cafe from the database.

GET

/all

Returns all cafes sorted by name.

GET

/search?loc=<location>

Search cafes by location.

POST

/add

Add a new cafe using form data.

PATCH

/update-price/<cafe_id>?new_price=x

Update the coffee price of a cafe.

DELETE

/report-closed/<cafe_id>?api-key=TopSecretAPIKey

Delete a cafe (requires API key which is TopSecretAPIKey for now).
